# Warung Laravel

Salin isi folder ini ke proyek Laravel (timpa routes/web.php), lalu:

1. .env:
   SHOP_NAME="Warung Bu Sari"
   SHOP_WA=6281234567890
   SELLER_PASSWORD=ganti-password-ini
   APP_TIMEZONE=Asia/Jakarta
2. php artisan migrate
3. php artisan storage:link
4. php artisan optimize:clear
